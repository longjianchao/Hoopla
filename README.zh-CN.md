# Hoopla —— 强引力透镜交互建模工具

[English](README.md) | **简体中文**

Hoopla 是一个运行在浏览器中的、人在回路（human-in-the-loop）的星系尺度强引力透镜建模工具。它只回答一个具体问题：**拿到一张透镜图像，什么样的透镜质量分布和背景源能产生我看到的这些弧？**

与其为了得到较好的参数限制范围反复调整初始参数再执行贝叶斯采样，你可以先在透镜上画一个椭圆、在源上画一个椭圆，实时看到预测的透镜成像如何变化，再让轻量优化器在几十秒内把模型参数拟合出来。得到的结果是一组物理上合理的参数，可导出为 JSON，作为后续完整建模的起点。

Hoopla 不是贝叶斯求解器的代替，它不给出带统计误差的最终参数约束。它负责的是交互式初始化——让用户所见即所得。

## 能做什么

- **读入真实或仿真图像** —— 支持 FITS 与 HDF5，可同时提供逐像素不确定度图与 PSF，并填写像素比例（arcsec/pixel）。
- **画图即建模** —— 在 `Mass Model` 画布上拖拽椭圆设定奇异等温椭球（SIE）质量模型参数（爱因斯坦半径、轴比、方位角、中心位置）；在 `Source Model` 画布上拖拽椭圆设定椭圆 Sérsic 源（有效半径、轴比、方位角、中心位置）。
- **实时看到透镜预测** —— `Source Plane` 画布显示源椭圆与透镜焦散线；`Image Plane` 画布显示预测的透镜成像与临界线，光标移动时同步更新。
- **自动精修模型** —— 点击 `Optimization`，以逐像素 χ² 为目标一次性拟合全部参数，过程中 χ² 曲线、各参数收敛轨迹与残差图实时刷新。
- **限定拟合区域** —— 通过 `Mask Radius` 与 `Apply Mask` 排除视场外围（干扰源、噪声较大的边缘）。
- **保存与对比模型** —— `Save Models` 将参数导出为 `.json`；`Load Models` 重新载入，并可在参数收敛图上叠加参考线进行对比。

## 安装

环境要求：Node.js（LTS，≥ v14）、一款现代浏览器，以及 Python 3（`npm start` 使用的静态服务器依赖它）。交互建模本身不需要 GPU。

```bash
git clone https://gitee.com/long-jianchao/Hoopla-Preprocessing_input_pics.git
cd Hoopla-Preprocessing_input_pics
npm install
npm start
```

<br />

其他启动方式：

```bash
npm run dev     # 带热更新的开发服务器（端口 8070），不依赖 Python
npm run build   # 构建静态文件到 ./dist，可部署到任意 Web 服务器
```

页面使用 ES 模块，必须通过 HTTP 访问；直接双击打开 `index.html` 无法运行。

## 准备输入数据

三个文件需共用同一像素网格，格式最好为 FITS 格式。

| 文件   | 是否必需  | 要求                                                      |
| ---- | ----- | ------------------------------------------------------- |
| 透镜图像 | 必需    | 透镜系统的表面亮度图像，应已完成本底/暗场、平场、天光扣除与宇宙线剔除等预处理；Hoopla 不做上游预处理。 |
| 噪声图  | 建议提供  | 逐像素 1σ 表面亮度不确定度。它应是噪声水平的平滑描述，而非一次噪声实现；取值需为正，不可含 NaN。    |
| PSF  | 优化时必需 | 小尺寸二维核，归一化到总流量为 1，峰值位于数组中心像素。                           |

若不提供不确定度图，程序会用图像本身做泊松式估计，这只是一个粗略近似，建议始终使用真实的噪声图。

此外还需提供观测的像素比例（arcsec/pixel），它决定画出的椭圆对应的角尺度。

## 使用流程

1. **载入数据** —— 点击 `Upload Images`，在弹窗中依次选择透镜图像、不确定度图与 PSF，填写像素比例后确认。执行优化前，界面底部的状态指示必须显示 `PSF Uploaded`。
2. **画质量模型** —— 在 `Mass Model` 画布上拖拽。椭圆大小对应爱因斯坦半径（仅作尺度参考，不代表物理边界），形状与朝向对应轴比与方位角。
3. **画背景源** —— 在 `Source Model` 画布上拖拽，确定 Sérsic 源椭圆。
4. **对齐弧结构** —— 在 `Source Plane` 画布上移动光标。画布处于 `Interactive` 状态时源位置跟随光标，`Image Plane` 持续重绘；调整到预测的蓝色轮廓在位置、数量与弯曲程度上与观测弧一致，再点击切换为 `Freezing` 冻结。
5. **优化** —— 点击 `Optimization`。χ² 曲线应先下降后趋于平台，各参数轨迹可判断是否稳定；结束后 `Source Plane` 会自动进入 `Freezing` 状态。
6. **检查诊断** —— 查看 `Residual Map`：噪声状残差说明拟合可接受，出现明显结构则意味着模型仍有遗漏。
7. **保存** —— 点击 `Save Models` 导出参数。若要和已知结果对比，用 `Load Models` 载入参考 `.json`，并保持 `Draw Model Comparison Line` 勾选。

## 如何解读诊断信息

- **χ² 曲线** —— 迭代早期出现波动是无导数搜索的正常现象；曲线稳定在平台说明收敛，后期持续大幅振荡则说明未收敛。
- **参数轨迹** —— 12 个子图对应 12 个自由参数，用于判断哪些参数仍在漂移或已被推向非物理取值。
- **残差图** —— 最重要的定性判据。应主要看弧的位置与形态是否被复现，而不只看最终的 χ² 数值。

## 常见问题

**χ² 曲线上下跳动，是不是出错了？**
参数空间探索阶段本来就会如此。只有当后期仍持续大幅振荡时，才说明模型没有收敛。

**参数跑到极端值（轴比或爱因斯坦半径明显异常）。**
说明优化陷入了局部极小，或模型假设与数据不符。建议中止、重新检查初始椭圆与掩膜，且不要将该结果用于分析。

**χ² 已经很低，但预测的弧仍然不对。**
优化器可能在低权重区域降低残差而牺牲了弧结构。此时应调整初始模型、核查不确定度图与 `Mask Radius`。

## 适用范围

Hoopla 面向单透镜、单源、星系尺度的系统，质量模型为 SIE、源为椭圆 Sérsic 剖面；不适用于星系团尺度、多平面透镜，以及需要多成分或像素化重建的系统。

它给出的参数是用于初始化的探索性点估计；需要统计上严格的约束时，应在此基础上开展完整的采样推断。
